# AC heating switch (toggle)

Dashboard toggle that turns AC heating on and off for the office. It is the AC
heating switch input of the AC Heating blueprint.

| Field         | Value                                                 |
| ------------- | ----------------------------------------------------- |
| Name          | `Office TM AC Heating`                                |
| Icon          | `mdi:radiator`                                        |
| Initial state | Start with off. Restore previous state after restart. |
